# Мини-система денежных переводов на Go

Проект, реализующий систему денежных переводов между пользователями.  
Разрабатывался поэтапно, с последовательным усложнением архитектуры — от простых структур до конкурентной обработки транзакций с помощью worker pool и защиты от гонок данных.

---

## v2 — Обработка транзакций

**Ветка:** [`v2`](../../tree/v2)

**Что сделано:**
- Добавлена структура `Transaction` (поля: `FromID`, `ToID`, `Amount`)
- Создана структура `PaymentSystem`:
  - `Users` — `map[string]*User` для быстрого доступа по ID
  - `TransactionQueue` — очередь транзакций
- Реализованы методы:
  - `AddUser` — добавление пользователя в систему
  - `AddTransaction` — добавление транзакции в очередь
  - `ProcessTransactions` — обработка всех транзакций из очереди с полной проверкой ошибок

**Почему:**
Переход от разрозненных данных к целостной системе управления.  
Отработка работы с мапами, поиском по ключу и обработкой множества операций.

---

## Итог

Проект полностью реализует **конкурентную систему денежных переводов**:

- Пользователи и их балансы
- Очередь транзакций
- Многопоточная обработка через Worker Pool
- Безопасная работа с данными через мьютексы
