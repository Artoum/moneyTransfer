# Мини-система денежных переводов на Go

Проект, реализующий систему денежных переводов между пользователями.  
Разрабатывался поэтапно, с последовательным усложнением архитектуры — от простых структур до конкурентной обработки транзакций с помощью worker pool и защиты от гонок данных.

## v3 — Конкурентная обработка (Worker Pool)

**Ветка:** [`v3`](../../tree/v3)

**Что сделано:**
- Метод `ProcessTransactions` переработан в `ProcessTransaction` — обработка **одной** транзакции
- Создан метод `Worker` — читает транзакции из канала и вызывает `ProcessTransaction`
- В `main`:
  - Создан буферизованный канал `chan Transaction`
  - Запущены **3 горутины-воркера**
  - Все транзакции отправлены в канал
  - Канал закрыт, ожидание завершения через `sync.WaitGroup`
- Очередь очищается после отправки, а не внутри обработки

**Почему:**
Переход от последовательной обработки к параллельной.  
Освоение паттерна **Worker Pool**, каналов, `range ch`, `close(ch)`, `sync.WaitGroup`.  
Подготовка к высоконагруженным сценариям.

## Итог

Проект полностью реализует **конкурентную систему денежных переводов**:

- Пользователи и их балансы
- Очередь транзакций
- Многопоточная обработка через Worker Pool
- Безопасная работа с данными через мьютексы
